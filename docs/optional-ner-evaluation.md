# Проверка явно включаемого NER

Основной профиль PR #20 остаётся режимом по умолчанию. Модель дополняет его только при `redact.ner: true`; подготовка весов выполняется отдельной командой.

## Регрессия режима по умолчанию

Через stdio MCP-прокси повторно пропущен ранее наблюдавшийся набор 400 случаев: 100 с ПДн и 300 безопасных. В конфигурации нет `ner`, `noModel: false`: проверяется именно отсутствие неявного включения. Это повторение регрессии, а не новое независимое измерение качества.

| Исход | lexical | trained |
|---|---:|---:|
| Пропуски ПДн из 100 | 15 | 15 |
| Лишние маски/удержания ПДн из 300 | 0 | 0 |
| Безопасные без изменений | 300 | 284 |
| Блокировки безопасных классификатором атак | 0 | 16 |

Результаты совпадают с принятым основным режимом. Словарь и правила распознавания не расширялись; прежние пропуски пар без отчества и некоторых фамилий с инициалами остаются. Подробности — в [первоначальном отчёте](russian-pii-evaluation.md).

## Проверка опционального пути

- Тесты проверяют, что отсутствующая настройка, `noModel: false`, `nerLabels` и `-deep` не включают модель. Это проверено и с повреждённым кэшем, и с валидным синтетическим графом. `noModel: true` имеет приоритет над `ner: true`.
- `ner: true` подключает cached ONNX recognizer, по умолчанию только персоны. Отсутствие бандла или ошибка инференса не превращаются в незаметное использование одних правил. Проверены MCP, hooks и ошибка инициализации при scan.
- Через настоящий MCP-прокси отдельно пройдены 12 небольших интеграционных примеров: кириллица, латиница, раздельные поля, мобильный и 6 безопасных контролей. Использован только репозиторный ONNX-граф размером 409 байт, который выдаёт заранее заданные logits для известных ID словаря. При выключенном NER в этой диагностике проходят 4 неизвестных правилам записи; при включённом тестовом графе маскируются все 6 целевых записей, 6 контролей сохранены. Это проверка соединения компонентов, **не точности обученного NER**.
- Native-тесты проверяют исходные UTF-8-смещения, имена после первого окна в 512 токенов, ограничение 32 окон и явную ошибку неполной проверки. Один recognizer разделяется между слоями proxy/hook и освобождается после завершения.
- Hooks больше не обходят приватность для коротких строк: проверены `Li Bo` и 11-значный мобильный. Проверка маскирования использует checked API и при ошибке скрывает непроверенный вывод.

Готовые обученные NER-веса не скачивались. Качество стандартного бандла на «Шахержон Тахержон», вариантах латинской записи и русских именах латиницей здесь не измерялось. [План для разных письменностей](name-scripts.md) отделяет текущие пробелы от предлагаемого расширения.
